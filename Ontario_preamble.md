# Overview

Define the AOU and ROF study areas, subsetting ROF by ecozone, and prepare species equivalency table for running LandR-fireSense simulations.

# Parameters

Provide a summary of user-visible parameters.


|paramName           |paramClass |default     |min |max |paramDesc                                                                                                                                                |
|:-------------------|:----------|:-----------|:---|:---|:--------------------------------------------------------------------------------------------------------------------------------------------------------|
|fireRegimePolysType |character  |FRT         |NA  |NA  |Polygon type to use for scfm `fireRegimePolys`: see `?scfmutils::prepInputsFireRegimePolys` for allowed types.                                           |
|studyAreaName       |character  |ON_AOU_5    |NA  |NA  |Should include one of 'ON_AOU' or 'ON_ROF' to identify the study area. May also include the Fire Regime Type ID in which to run the model.               |
|useAgeMapkNN        |logical    |FALSE       |NA  |NA  |if TRUE, use kNN age maps, corrected with fire polygons data; if FALSE, use Raquel's predicted age map from `ROF_age`.                                   |
|.resolution         |numeric    |250         |NA  |NA  |raster pixel size, in metres, to use for simulation. Either 250 or 125.                                                                                  |

|.saveInitialTime    |numeric    |NA          |NA  |NA  |Describes the simulation time at which the first save event should occur.                                                                                |

# Events

This module consists of a single `init` event that performs all the data preparation.
